# Philippines vACC Knowledge Base

> The central learning repository for observers, student controllers, and pilots operating within Philippine airspace.

---

## About

This knowledge base serves as the official reference guide for procedures and systems used within the Manila Flight Information Region (FIR) and the Manila Area Control Center (ACC). It covers ATC theory, local procedures, and pilot operations specific to the Philippine vACC (VATPHIL).

Inspired by [Gander Oceanic's](https://github.com/czqo) knowledge base, this site is built on [MkDocs Material](https://github.com/squidfunk/mkdocs-material) by [squidfunk](https://github.com/squidfunk).

---

## Contributing

All VATPHIL controllers and staff members are eligible to contribute. Contributions from unverified accounts will not be merged.

### Getting Started

1. **Fork** this repository.
2. Navigate to the `docs/` folder and make your changes.

   | Directory | Purpose |
   |-----------|---------|
   | `atc/`    | Controllers and observers |
   | `pilots/` | Pilot procedures and guides |
   | `notams/` | Active NOTAMs |

3. Open a **pull request** including your **Name** and **VATSIM CID** for verification.

> [!TIP]
> Each directory contains a `.pages` YAML file that controls page titles and display order. Update this when adding new pages.

For full MkDocs Material authoring reference, see the [official documentation](https://squidfunk.github.io/mkdocs-material/).
